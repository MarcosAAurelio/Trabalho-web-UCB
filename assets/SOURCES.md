# Fontes dos assets

Assets originais do projeto Happy / NLW 3, Rocketseat:
https://github.com/rocketseat-education/nlw-03-discovery/tree/main/public/images

- `logo.svg`, `map-marker.svg`, `arrow.svg`, `arrow-back.svg`, `arrow-white.svg`, `plus.svg`, `clock.svg`, `info.svg`, `info-red.svg`, `whatsapp.svg`, `home.jpg`, `logo-icon.png`, `add-file.svg`, `red-x.svg`, `remove-file.svg`: arquivos oficiais, sem alteracoes.
- `bg.svg`: ilustracao oficial, viewBox `0 0 554 674`.
- `landing.svg`: copia de `bg.svg`, nome usado pelo projeto local.
- `landing-ilustra.svg`: arquivo oficial de https://github.com/rocketseat-education/nlw-03-omnistack/blob/master/web/src/assets/images/landing-ilustra.svg. Conteudo identico a `bg.svg`.
- `arrow-forward.svg`: copia de `arrow.svg`, seta marrom (#8D734B) usada em botao amarelo.
- `map-pin.svg`: copia de `map-marker.svg`, marcador amarelo original.

Fonte Nunito oficial Google Fonts, normal variavel (pesos 200 a 1000):
https://fonts.google.com/specimen/Nunito
https://github.com/google/fonts/tree/main/ofl/nunito

- `nunito.woff2` e `nunito-latin.woff2`: mesmo subset Latin; inclui caracteres acentuados do portugues.
- `nunito-latin-ext.woff2`: subset Latin Extended complementar.
- URLs dos downloads: https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofINeaB.woff2 e https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofIO-aBXso.woff2.
- `NUNITO-LICENSE.txt`: SIL Open Font License fornecida pelo Google Fonts.
- `HAPPY-LICENSE.md`: licenca MIT fornecida no repositorio oficial Rocketseat.

Todos os SVG foram verificados como XML valido com raiz svg. Nenhuma foto de referencia do usuario foi modificada.
